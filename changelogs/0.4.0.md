## Location Tooltip 0.4.0

Location Tooltip now runs on Minecraft 1.21.1, alongside 1.20.1.

### Added
- **Minecraft 1.21.1 support.** The whole mod works on 1.21.1 now: regions and the HUD pill, the Admin Compass and naming screens, granular protections, structure auto-tagging, and Waystones village naming. Download the file that matches your Minecraft version.

### Notes
- Each Minecraft version is a separate download (`0.4.0+1.20.1` and `0.4.0+1.21.1`). Nothing changes for existing 1.20.1 worlds, your regions and settings carry over untouched.

---
*Requires Fabric API. Mod Menu, Cloth Config, and Waystones are optional.*
