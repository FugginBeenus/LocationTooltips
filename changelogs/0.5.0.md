## Location Tooltip 0.5.0

Location Tooltip now runs on Minecraft 1.20.1, 1.21.1, 1.21.11, 26.1 and 26.2.

### Added
- **Minecraft 1.21.11 support.** Everything works: regions and the HUD pill, the Admin Compass and naming screens, granular protections, structure auto-tagging, and Waystones village naming.
- **Minecraft 26.1 and 26.2 support.** Regions, the HUD pill, the Admin Compass panel, protections, structure auto-tagging and commands all work.

### Known limits on the newer versions
- **The Admin Compass needle does not spin on 1.21.11 and newer.** Minecraft replaced the system that drove it with data-driven item models, and the registry mods would need is not open yet. The compass still opens the panel and crafts normally.
- **Region outlines are traced with particles on 26.1 and 26.2** instead of drawn as boxes. Minecraft rewrote how the world is drawn and Fabric has not shipped a replacement hook yet, so no mod can draw the boxes there for now. Holding the Admin Compass still shows you where the edges are.
- **The config screen has no live preview on 26.1 and 26.2.** Your settings still save normally.

### Notes
- Each Minecraft version is a separate download. Pick the file that matches your game.
- Nothing changes for existing worlds. Your regions and settings carry over untouched.

---
*Requires Fabric API. Mod Menu, Cloth Config, and Waystones are optional.*
