## Location Tooltip 0.5.1

Two new pills, real names for villages, and a couple of fixes.

### Added

- **Coordinates and biome pills.** Two new pills that match the ones you already have. Turn either on in the config and put it wherever you like on the screen. Pills that share a spot now line up in a row and size themselves identically, so they stop overlapping each other.

- **Villages get proper names.** Instead of "Plains Village" you get names like Winterdell or Frost Shire, picked from word lists that lean on where the village sits. Snowy villages lean cold, desert villages lean dry, but there is enough randomness left in that anything can turn up anywhere. The name is worked out from the village's position, so it stays the same every time you load the world. Waystones still wins wherever it has named a village, so this only fills the gap. Turn it off with `/ltregion structures villagenames off`, or with `nameVillages` in the structures config.

- **Players can name villages they find.** Off by default. Once a server turns it on, a player standing in a village can open the Admin Compass and name it with the Name button, or use `/ltname`. Naming a village gives them the name and nothing else, so they get no say over its protections. Whoever names it is remembered, so nobody can rename it over them, and the automatic namer leaves it alone from then on. Admins can always rename it and take it back. Turn it on with `/ltregion structures villagenames players on`.

### Fixed

- **Mob Griefing and Item Pickup actually do something now.** Both have been sitting in the protection grid taking a setting and quietly doing nothing. Mob Griefing now stops endermen picking blocks up and putting them down, zombies breaking doors, ravagers wrecking crops and leaves, and withers and the ender dragon chewing through walls. Item Pickup stops players collecting dropped items off the ground. Creeper blasts are still handled by the Explosions flag, since an explosion is an explosion whoever set it off.

- **`/ltregion flags` tells you the truth.** It used to list what the region you are standing in had set, and report anything unset as "inherit, default allow" even when a region further out was denying it. It now shows what is actually in effect and names the region that decided it, so you can find the one you forgot about.

- **The screens fit smaller windows.** The Admin Compass panel and the region naming screen measure the window and shrink to fit instead of running off the edge, and the search box shrinks along with the panel.

- **Region borders no longer smear.** The boxes were being drawn through a render type that joins the corners into one long streak across the world. They draw as proper boxes now.

### Notes

- Each Minecraft version is a separate download. Pick the file that matches your game.
- Nothing changes for existing worlds. Your regions and settings carry over untouched.

*Requires Fabric API. Mod Menu, Cloth Config, and Waystones are optional.*
