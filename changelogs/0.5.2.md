## Location Tooltip 0.5.2

Mostly a polish pass. The pills look the way they were always meant to out of the box, and the mod finally looks like something in your mod list.

### Changed

- **New default look for the pills.** Smaller text, tighter padding and a much lighter background, so the HUD sits quietly at the top instead of shouting at you. Coordinates and biome are on by default now and line up in the same row as the region name and clock.

  If you have played before, your existing settings are yours and nothing is touched. This only affects a fresh install. To take the new look, delete `config/locationtooltip.json` and let it write itself again.

- **New icons for the protection flags.** The little symbols along the bottom of each row in the Admin Compass, and in the protection grid, have been redrawn.

- **A proper icon in Mod Menu.** Location Tooltip had no icon at all, so it showed up blank. It has its logo now, along with a description that actually says what the mod does and links to the wiki, the source and the issue tracker.

### Added

- **A wiki.** Twelve pages covering installation, making your first region, the pills, protections, the Admin Compass, villages, all the commands, every config setting and troubleshooting. It lives at [the wiki](https://github.com/FugginBeenus/LocationTooltips/wiki).

### Fixed

- **The licence is a real licence.** `LICENSE` had a placeholder line in it instead of the MIT text, so the mod was technically unlicensed despite saying MIT everywhere. It is the actual MIT licence now.

### Notes

- Each Minecraft version is a separate download. Pick the file that matches your game.
- Nothing changes for existing worlds. Your regions and settings carry over untouched.

---
*Requires Fabric API. Mod Menu, Cloth Config, and Waystones are optional.*
